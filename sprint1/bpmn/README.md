## 3. Порядок відкриття та редагування моделей

### Варіант 1. Онлайн-редактор demo.bpmn.io (Рекомендовано)
1. Перейдіть на вебсторінку https://demo.bpmn.io.
2. Натисніть кнопку «Open» у лівому верхньому куті та оберіть файл `01_testing.bpmn` або `02_course_creation.bpmn`.
3. Для модифікації використовуйте інтерактивну палітру фігур і контекстне меню (іконка гайкового ключа) для налаштування типів подій і шлюзів.
4. Для збереження результатів натисніть «Download BPMN diagram» та експортуйте векторну графіку «Download SVG image».

### Варіант 2. Інструмент diagrams.net (draw.io)
1. Відкрийте онлайн-сервіс https://app.diagrams.net.
2. Відкрийте вихідний файл через меню `File -> Open From -> Device`.
3. Перевірте коректність відображення зв'язків та експортуйте результат у векторному форматі через `File -> Export as -> SVG`.

## 4. Відповідність нормативам Спринта 1 (команда з 3 осіб)
- Кількість змодельованих бізнес-процесів: **2 моделі** (норматив: >= 2).
- Типи логічних операторів (шлюзів):
  1. *Exclusive Gateway (XOR data-based)* — перевірка спроб та аудит курсу.
  2. *Event-Based Gateway (XOR event-based)* — вибір гілки за першою подією (студент vs таймер).
  3. *Parallel Gateway (AND fork & join)* — одночасне наповнення чотирьох розділів курсу.
  *(Сумарно: 3 типи шлюзів при нормативі >= 3).*
- Наявність підпроцесу: реалізовано розгорнутий підпроцес *«Підпроцес опрацювання питань тесту»* з власними початковою і кінцевою подіями.
- Пули та доріжки: відповідають ролям з каталогу продукту («Студент», «Викладач», «Менеджер курсів», «Система LMS»).
- Потоки повідомлень (Message Flows): реалізовано коректний обмін між пулом користувача та пулом навчальної платформи.
