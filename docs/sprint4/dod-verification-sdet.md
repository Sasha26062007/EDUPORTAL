## 2. Перелік переданих файлів у репозиторії

1. `pom.xml` — головний файл конфігурації проєкту;
2. `.gitignore` — виключення збіркових директорій `target/` та файлів IDE;
3. `src/main/java/ua/kpi/tzyapz/eduportal/*` — повний комплект бізнес-моделей та класів модуля v1;
4. `src/test/java/ua/kpi/tzyapz/eduportal/EnrollmentValidatorTest.java` — основний юніт-набір тестів Олександра Кираківського;
5. `src/test/java/ua/kpi/tzyapz/eduportal/ui/BaseUiTest.java` — базовий клас конфігурації WebDriver;
6. `src/test/java/ua/kpi/tzyapz/eduportal/ui/pages/*` — 6 класів Page Object Model (`BasePage`, `LoginPage`, `DashboardPage`, `CoursePage`, `CourseEnrollmentPage`, `AssignmentPage`, `GradebookPage`);
7. `src/test/java/ua/kpi/tzyapz/eduportal/ui/*` — 4 класи WebDriver-тестів (11 тест-методів);
8. `selenium-ide/eduportal.side` — збережений проєкт Selenium IDE;
9. `selenium-ide/export/*` — чернетки експорту тестів;
10. `docs/*` — повний пакет документації інженера SDET (`sdet-report.md`, `ui-scenarios.md`, `coverage-matrix.md`, `surefire-summary.md`, `blitz-prep-sprint4.md`, `defects/*`).
