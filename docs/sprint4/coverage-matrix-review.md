## 1. Загальна оцінка повноти покриття вимог SRS

Скрам-майстер Денис Бучинський здійснив детальне рецензування матриці покриття бізнес-правил модуля, розробленої Тест-аналітиком Олександром Пархоменком та Керівником тестування Володимиром Костенком.

### Критерії оцінки:
1. **Повнота трасування:** 100% бізнес-правил BL-10..BL-80 мають зв'язані автотести.
2. **Адекватність тест-дизайну:** для кожної межі застосовано техніку Boundary Value Analysis (BVA) з трьома точками ($N-\Delta, N, N+\Delta$).
3. **Негативні випадки:** наявність винятків (`assertThrows`) на некоректні вхідні аргументи (null, від'ємні числа, вихід за межі діапазону).
4. **Рівномірність внеску:** кожен із 5 членів команди має закріплені авторські юніт-тести ($\ge 3$ на особу).
