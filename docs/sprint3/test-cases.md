## Регламент структури та автономності тест-кейсів
1. **Єдина 6-полева обов'язкова структура:** Ідентифікатор, Вимога SRS 1.1, Заголовок, Передумови, Кроки виконання, Очікуваний результат (+ службові поля: Пріоритет, Тип, Автор, Рецензент, Дата, Статус).
2. **Абсолютна автономність (Zero Dependency):** Крок 1 кожного тест-кейсу завжди починається з відкриття URL-адреси стенду / форми входу; фінальний крок завжди здійснює вихід із системи («Меню користувача» $\rightarrow$ «Вихід» або завершення сеансу). Жоден тест-кейс не посилається на результати інших тестів.
3. **Об'єктивність очікуваних результатів:** Усі формулювання результатів містять лише перевірювані факти (текст повідомлень, URL-адреси, кольори плашок, стан кнопок) без розмитих оціночних суджень «працює коректно».
