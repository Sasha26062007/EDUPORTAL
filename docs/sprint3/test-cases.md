## TC-01 — Успішний вхід студента з валідними обліковими даними та вихід із системи

- **Вимога:** F-10, GUI-10
- **Пріоритет / тип:** High / Позитивний
- **Передумови:** Стенд скинуто (S1). Акаунт student / sandbox24 активний. Chrome 130, нова сесія інкогніто.
- **Кроки та очікувані результати:**
  1. Відкрити https://sandbox.moodledemo.net/login/index.php → *Сторінка «Вхід до системи» з полями «Ім'я входу», «Пароль», посиланням «Забули пароль?» і кнопками «Увійти», «Увійти як гість».*
  2. У поле «Ім'я входу» ввести student → *У полі відображається student.*
  3. У поле «Пароль» ввести sandbox24 → *Символи пароля приховані.*
  4. Натиснути кнопку «Увійти» → *Редірект на /my/; блок «Мої курси»; у меню — «Student User».*
  5. У меню користувача натиснути «Вихід» → *Сеанс завершено, відкрито сторінку входу.*
- **Статус:** Approved; рецензент Панайотов О. (Скрам-майстер / Рецензент), 20.10.2026.
