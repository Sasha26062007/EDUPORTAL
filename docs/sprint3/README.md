### 4.2. Офіційно затверджений перелік вимог, не покритих ручним Web UI-тестуванням у Спринті 3 (з технічними причинами)

Відповідно до п. 3 обов'язків Керівника тестування та критеріїв DoD, нижче зафіксовано вимоги `SRS 1.1`, які не підлягають повному ручному виконанню через веб-інтерфейс демо-стенду `sandbox.moodledemo.net` у Спринті 3, із зазначенням точних технічних причин та етапу їх верифікації:
