**Непокриті або частково покриті вимоги та причини:**

- `BL-10`, `BL-80` — внутрішні методи Java-модуля (`weightedTotal`, `violations`), недоступні через Web UI; JUnit 5 у Спринті 4.
- `BL-70` — через UI перевірено лише збіг кодового слова; період, місткість і пререквізит — JUnit 5.
- `P-10` — навантажувальні перевірки на публічному demo заборонені (§5.4 методички); у TC-10 виконано лише однокористувацький замір.
- `P-20` — навантажувальний прогін 200 користувачів не проводився; окремого заміру статичних сторінок у Спринті 3 не було.
- `S-10` — хеші паролів і 2-годинний таймаут недоступні на demo; у TC-01 спостережено HTTPS.
- `U-10` — потрібна вибірка ≥ 10 користувачів; хронометраж сценарію в Спринті 3 не проводився.
- `U-20` — перевірено українські підписи форми входу; перемикання на англійську окремим кейсом не перевірялося.
- `D-10`, `D-20` — посібники й контекстна довідка постачаються поза demo; перевірка документації не входить у Web UI-прогін.

## 9. Обмеження та ризики

- Demo скидається щогодини; тривалі сценарії розбито на короткі кейси, дані перестворюються за S7.
- Demo не надсилає пошту: F-20 перевірено до моменту відправлення листа; підтвердження email у F-110 не перевірялося.
- Навантажувальні перевірки на публічному стенді заборонені; P-10 оцінено однокористувацьким заміром у TC-10, P-20 не перевірялося.
- Java-модуль бізнес-логіки не підключений до demo: BL-10, BL-40…BL-80 перевірятимуться JUnit 5 у Спринті 4; через UI покрито лише видимі правила (BL-20, BL-30, частково BL-50/BL-60/BL-70).
- `TC-16` і `TC-26` заблоковані дефектами P2 і будуть повторені після виправлення у Спринті 5.
