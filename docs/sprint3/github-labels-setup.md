## 1. Структура міток (Labels Taxonomies)

Відповідно до розділу 4.15 методичних вказівок Спринту 3, у репозиторії налаштовано єдину систему міток із колірним кодуванням за трьома вимірами:

### 1.1. Рівень серйозності (Severity) — вплив на систему та користувача
| Назва мітки | Колір HEX | Опис призначення |
|:---|:---:|:---|
| `severity:blocker` | `#B60205` (темно-червоний) | Повна неможливість запуску системи чи входу; блокує будь-яке тестування |
| `severity:critical` | `#D93F0B` (червоний) | Відмова системи, спотворення розрахунку оцінок (BL), втрата даних, обхід захисту |
| `severity:major` | `#E99695` (світло-червоний) | Серйозний збій функціональності, порушення логіки дедлайнів або завантаження файлів |
| `severity:normal` | `#FBCA04` (жовтий) | Стандартний дефект: функція працює некоректно, але існують робочі альтернативи |
| `severity:minor` | `#FEF2C0` (світло-жовтий) | Незначне відхилення поведінки інтерфейсу, дрібні помилки розмітки або адаптивності |
| `severity:trivial` | `#C5DEF5` (світло-блакитний) | Косметичні зауваження: друкарські помилки, неперекладені слова, неідеальний шрифт |

### 1.2. Пріоритет усунення (Priority) — черговість для розробника
| Назва мітки | Колір HEX | Опис призначення |
|:---|:---:|:---|
| `priority:P1` | `#B60205` | Критичний пріоритет: блокує прогін тест-кейсів, підлягає негайному виправленню |
| `priority:P2` | `#D93F0B` | Високий пріоритет: блокує частину пов'язаних перевірок або впливає на ключові модулі |
| `priority:P3` | `#0E8A16` (зелений) | Звичайний пріоритет: дефект не блокує інші перевірки, виправляється у плановому порядку |

### 1.3. Життєвий цикл дефекту (Status)
| Назва мітки | Колір HEX | Стан у життєвому циклі дефекту (§4.14) |
|:---|:---:|:---|
| `status:new` | `#1D76DB` | Звіт щойно створено тестувальником, очікує перевірки рецензентом |
| `status:open` | `#0052CC` | Дефект підтверджено, призначено відповідального розробника |
| `status:fixed` | `#5319E7` | Виправлено розробником у новій збірці, очікує повторного тестування |
| `status:verified` | `#0E8A16` | Виправлення перевірено та підтверджено успішним повторним тестом |
| `status:reopened` | `#E11D48` | Дефект повторився після «виправлення» або виявлено регресію |
| `status:closed` | `#6A737D` | Життєвий цикл завершено, звіт закрито |
