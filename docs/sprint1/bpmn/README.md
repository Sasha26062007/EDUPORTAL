## 1. Склад каталогу інженерних моделей

У цьому каталозі представлено комплект верифікованих вихідних BPMN 2.0 XML-файлів (`.bpmn`), їхніх векторних графічних експортів (`.svg`) та протоколу перехресного рецензування:

1. `01_testing.bpmn` / `01_testing.svg` — Модель бізнес-процесу №3 «Проходження тесту» (Quiz Attempt):
   - Учасники: пули «Студент» (з доріжкою «Студент») та «Система LMS (ЕдуПортал)» (з доріжкою «Сервіси LMS»).
   - Логіка: шлюз XOR за даними («Спроби доступні?»), проміжна подія-повідомлення допуску, розгорнутий підпроцес опрацювання питань тесту з 4 внутрішніми об'єктами, шлюз XOR за подіями («Контроль завершення»: ручне завершення або таймер), автооцінювання за QuizScorer, об'єкт даних «Бланк відповідей на тест», текстова анотація з асоціацією та 5 міжпульних потоків повідомлень (Message Flows).
2. `02_course_creation.bpmn` / `02_course_creation.svg` — Модель бізнес-процесу №4 «Створення та наповнення курсу» (Course Creation):
   - Учасники: єдиний пул «Система ЕдуПортал (Створення курсу)» із 3 доріжками («Менеджер курсів», «Викладач», «Система LMS»).
   - Логіка: вхідний синхронізуючий шлюз XOR Merge для прийому початкового потоку та петлі доопрацювання (усунення ризику дедлоку), паралельне наповнення 4 компонентів через шлюзи AND Fork і AND Join (лекції, завдання, тести, форум), аудит менеджером, шлюз XOR перевірки вимог з циклом повернення на доопрацювання, публікація курсу в LMS, об'єкт даних «Програма та матеріали навчального курсу», текстова анотація з асоціацією.
3. `review.md` — Офіційний протокол перехресного рецензування обох моделей за 10 пунктами нормативного чек-листа BPMN 2.0 (§4.9).

## 2. Порядок відкриття та перевірки моделей в інструментах

### Варіант 1. Онлайн-редактор demo.bpmn.io (Штатний інструмент)
1. Відкрийте браузер і перейдіть на вебсторінку https://demo.bpmn.io.
2. Натисніть кнопку «Open» у лівому верхньому куті та оберіть файл `01_testing.bpmn` або `02_course_creation.bpmn`.
3. Діаграма автоматично розгорнеться на полотні зі збереженням усіх фігур, підпроцесів, доріжок, анотацій та трасованих ліній зв'язку (`BPMNEdge` / `di:waypoint`).
4. Для збереження діаграми натисніть «Download BPMN diagram».
5. Для експорту векторної графіки натисніть «Download SVG image». Для генерації PDF надрукуйте відкритий SVG з браузера у векторному форматі (Ctrl+P -> Зберегти як PDF).

### Варіант 2. Інструмент diagrams.net (draw.io)
1. Відкрийте онлайн-сервіс https://app.diagrams.net.
2. Відкрийте файл через меню `File -> Open From -> Device` та оберіть потрібний `.bpmn` файл.
3. Переконайтеся в повному збереженні геометрії елементів та коректності зв'язків.

## 3. Відповідність нормативам Спринта 1 (Норматив «3 особи»)

- **Кількість моделей:** 2 моделі ключових процесів (норматив $\ge 2$).
- **Різноманітність логічних операторів (шлюзів):**
  1. *Exclusive Gateway (XOR Data-based)* — «Спроби доступні?», «Синхронізація входу/повернення», «Вимоги до курсу виконано?».
  2. *Event-Based Gateway (XOR Event-based)* — «Очікування допуску», «Контроль завершення».
  3. *Parallel Gateway (AND Fork & Join)* — «Паралельне наповнення компонентів курсу», «Синхронізація завершення наповнення».
  *(Сумарно: 3 різних типи шлюзів при нормативі $\ge 3$).*
- **Розгорнутий підпроцес:** «Підпроцес опрацювання питань тесту» з власними Start Event, Task, Task, End Event.
- **Пули та доріжки:** Кожна модель має пули та доріжки, названі за ролями з легенди продукту (Студент, Викладач, Менеджер курсів, Система LMS).
- **Потоки повідомлень (Message Flows):** 5 міжпульних інформаційних потоків у моделі тестування.
- **Артефакти даних та анотації:** Реалізовано об'єкти даних («Бланк відповідей на тест», «Програма та матеріали навчального курсу») та текстові анотації з асоціаціями до відповідних блоків.
