   - Згенеровано повний набір координат Diagram Interchange (`BPMNShape` для всіх внутрішніх вузлів підпроцесу та `BPMNEdge` для всіх 20+ потоків управління і 5 потоків повідомлень).

2. **Модель 2 («Створення та наповнення курсу»):**
   - Введено шлюз виключного АБО `Gateway_XOR_ReworkMerge` перед шлюзом паралельного розгалуження `Gateway_Fork_Content` для усунення дедлоку при повторному циклі доопрацювання курсу (§4.5).
   - Додано текстову анотацію `TextAnnotation_2` з асоціацією до шлюзу наповнення.
   - Згенеровано повний набір координат `BPMNEdge` та відповідний SVG-експорт.
3. **Узгодженість зі специфікацією:**
