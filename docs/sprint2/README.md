## 4. Зведена стратегія тестування (Test Strategy)

План тестування продукту «ЕдуПортал» (`test-plan.md`) охоплює:
- **Усі 7 обов'язкових рівнів тестування:** Модульне (Unit), Інтеграційне (Integration), Приймальне до тестування (Smoke/BVT), Системне (System), Альфа (Alpha), Бета (Beta), Приймальне замовником (CAT/UAT).
- **16 конкретних типів тестування** (при нормативі для 5 осіб $\ge 15$): Функціональне, GUI, Регресійне, Безпеки (Security/IDOR), Продуктивності (Load), Стресове (Stress), Граничних значень, Потоків даних, Сумісності (Cross-browser), Стрибкове (Spike — 500 одночасних студентів), Надійності (Reliability), Доступності (High Availability), Локалізації (українська мова, літери і, ї, є, ґ), Відновлення (Failover), Конфігураційне, Інтерфейсів (REST API).
- **2 незастосовні типи з обґрунтуванням:** 
  - *Порівняльне (Benchmarking)* — відсутня попередня продакшн-версія системи (greenfield проект);
  - *Апаратне / Інсталяційне на клієнті* — хмарний веб-сервіс (SaaS), що не потребує локального клієнтського ПЗ.
